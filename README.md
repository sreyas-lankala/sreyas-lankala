## 🚀 Featured Projects

### 🏗️ [Enterprise Data Quality & Governance Platform](https://github.com/sreyas-lankala/enterprise-data-platform)
> Snowflake · dbt · Apache Airflow · GitHub Actions · SQL · Python

Medallion-architecture platform (RAW → STAGING → MART) with a metadata-driven quality rule engine and an operational observability layer. Pre-load and post-load validation is orchestrated in Airflow with CI/CD quality gates in GitHub Actions, so a failing control halts promotion instead of publishing bad data silently.

**By the numbers:** 40+ SQL scripts · 25+ dbt models · 65+ configurable quality rules · 6 governance schemas · CI/CD via GitHub Actions
